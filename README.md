## 4. 왜 이 멘토링인가

9~25년차 경력직을 1:1로 멘토링하며 반복해서 본 문제입니다.

| 관찰 | 내용 |
|---|---|
| JD를 읽지 않고 이력서부터 고친다 | 공고는 회사가 지금 풀고 싶은 문제인데, 자기 경력 나열에서 출발한다 |
| 이력서가 업무 목록이다 | 직책과 담당 업무만 있고 판단·결과·숫자가 없다. 연차가 높을수록 실제보다 작게 쓴다 |
| 면접을 암기로 준비한다 | 예상 질문을 외워도 꼬리 질문 하나에 무너진다 |
| 협상을 처음 해 본다 | 하한선과 근거 없이 오퍼를 받고, 기본급 외 조건을 모른 채 수락한다 |
| 문서끼리 서로 다르다 | 연차·성과 수치가 이력서, 면접, 레퍼런스에서 다르게 나와 신뢰를 잃는다 |

경력자는 일은 잘하지만 **채용 시장의 문법**을 배운 적이 없습니다. 그 문법을 채용을 결정하던 사람의 시선으로 전합니다.

## 5. 멘토링 ① 경력직 이직 실전 4세션

공고에서 출발합니다. **JD → 이력서 → 면접 → 협상** 순서입니다.

| 세션 | 주제 | 핵심 내용 | 결과물 |
|---|---|---|---|
| 1 | JD 해독과 지원 판단 | 필수·우대·반복 키워드 분해, 공고 뒤의 채용 이유 추론, 결재선(인사→현업 팀장→임원)별 관심사, 충족·부분·공백 판정과 지원·보류 결정 | JD 매칭표 |
| 2 | 이력서·경력기술서·자기소개서 | 첫 줄 포지셔닝, 문제→판단→실행→결과 문장, 수치에 측정 기준 병기, 연차·공백·이직 사유 처리, 공고별 버전 관리 | 첫 화면 수정본, 성과 카드 |
| 3 | 면접 | 60초 오프닝, 질문 유형 분류, 꼬리 질문 대응, 모르는 질문은 범위 확인→가설→확인 방법, 리더급 질문(판단·위임), 역질문 | 예상 질문과 답변 틀 |
| 4 | 연봉·처우 협상 | 오퍼 전 하한선·근거 확정, 총보상 비교, 먼저 숫자를 말하지 않는 법, 비금전 조건, 레퍼런스 체크 대비 | 협상 시나리오, 오퍼 비교표 |

**공통 원칙**: 서류·면접·레퍼런스가 같은 사람을 말해야 합니다.

**Before → After 예시 (제 이력서 기준)**

| Before | After |
|---|---|
| 티몬 국내본부장, 여행·레저 사업 총괄 | 3인 TF로 시작해 약 150명 사업조직을 구축하고 GMV 연 4,000억 원 규모로 성장시킨 커머스 사업 총괄 |
| 마케팅 비용 효율화 | 파트너사와 광고 지면·티켓 교환 프로모션을 설계해 CAC를 약 25,800원에서 약 15,000원으로 낮춤 |
